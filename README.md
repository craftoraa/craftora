# Craftora — Creator Marketplace MVP

A polished frontend MVP for a creator-first marketplace.

## Run locally

Requirements:
- Node.js 18+

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## What is included

- Responsive landing page
- Marketplace with search and category filtering
- Product cards and product detail modal
- Wishlist
- Shopping cart
- Creator application modal
- Creator dashboard mockup
- How-it-works page
- Responsive mobile navigation
- Modern marketplace UI

## Important

This is a frontend MVP/demo. Authentication, PostgreSQL/Supabase, real admin moderation, real payments, order persistence, and delivery APIs are not connected yet.

The product data is currently stored in `src/main.jsx`. Replace the image URLs with your own assets or an object storage service before production.
